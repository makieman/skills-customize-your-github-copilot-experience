# Assignment Markdown Structure Guidelines

Assignment markdown files must:

- Be named `README.md` within an assignment folder.
- Follow the structure in [`templates/assignment-template.md`](templates/assignment-template.md).
- Include the template's title, objective, and tasks sections with their required icons.
- Use a short, descriptive title and a 1-2 sentence objective.
- Give each task an action-oriented name, a clear description, and specific, measurable requirements.
- Use code blocks for example input and output when helpful.

Do not add extra sections unless the assignment explicitly requires them.
